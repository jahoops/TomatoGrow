# TomatoGrow Current Controls

## Farm Controls

- `Arrow keys`: move the selected farm plot
- `Tab`: cycle selected seed
- `P`: plant selected seed
- `W`: water selected plot
- `H`: harvest selected plot
- `N`: advance to the next day
- `S`: sell sellable inventory from the farm view
- `Y`: buy the selected seed once
- `Shift+Y`: buy as many of the selected seed as possible
- `E`: expand the farm
- `R`: reset the entire game state

## Screen Navigation

- `I`: inventory screen
- `F2`: stats screen
- `F3`: machines screen
- `F4`: help screen
- `F8`: storage screen
- `F9`: computer screen
- `F10`: market screen
- `F11`: activity ledger screen
- `Esc`: return to Farm from any sub-screen
- `Esc` on the Farm screen: quit the game

## Bots

- `1`: unlock Planter Bot
- `2`: unlock Watering Bot
- `3`: unlock Harvester Bot
- `V`: run Planter Bot now
- `B`: run Watering Bot now
- `X`: run Harvester Bot now
- `G`: run the full farm cycle helper
- `T`: toggle the Watering Bot state

## Machines

- `Page Up`: select previous machine
- `Page Down`: select next machine
- `M`: start the selected processor machine
- `O`: collect output from the selected processor machine

## Storage

- `C`: deposit sellable inventory into shared storage
- `U`: withdraw all items from shared storage
- `S` on the storage screen: sell from shared storage

## Market

- `F10`: open the Supply Market screen
- `1`-`9`: buy the matching listed market offer while on the market screen

## Autoplay

- `F5`: toggle Auto Play on or off
- `F6`: run a single Auto Play step
- `F7`: reset Auto Play counters

Auto Play remains enabled while paused, but it does not take steps until the game is resumed.

## Save / Load

- `F12`: save the current game
- `Shift+F12`: request load confirmation
- `Y` during load confirmation: confirm load
- `N` during load confirmation: cancel load
- `Esc` during load confirmation: cancel load

Loading returns the UI to the Farm screen, unpaused, with Auto Play off.

## Pause

- `Space`: pause or resume the game

When paused, navigation still works, but gameplay actions are blocked.

## Help

- `F4`: open the Help / Controls screen

## Ledger

- `F11`: open the Activity Log screen

## Computer

- `F9`: open the Farm Computer overview screen

## Debug

- `F1`: toggle debug details on or off
